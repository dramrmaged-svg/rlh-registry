Local-storage edition. All data lives only in this browser (no server, no multi-user access — two people opening this file cannot see each other's entries). Export a backup regularly: clearing browser data, or opening this file on a different device, will lose anything not exported. A multi-user server version (NestJS + PostgreSQL backend, already built in this repository under apps/api / apps/web) is available to move to whenever you're ready — it uses exactly the same episode data model and calculation engine as this file, so nothing recorded here needs to be re-entered; a backup exported from here can be migrated in.
