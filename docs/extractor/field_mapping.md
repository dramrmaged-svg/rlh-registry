## 3. Field notes (all catalogue entries with a note)

- `patient.sex` → `Patient.sex`: Needed for MELD 3.0. Unknown sex is NOT defaulted to male (registry legacy behaviour is not reused).
- `baseline_assessment.diagnosis` → `Diagnosis.tumourType`: Normalised to registry DIAGNOSIS_TUMOUR_TYPE vocabulary.
- `baseline_assessment.ascites` → `ClinicalScore.ascites`: Child-Pugh input. Radiological ascites ≠ clinical grade — verification required for CP use.
- `baseline_assessment.encephalopathy` → `ClinicalScore.encephalopathy`: Child-Pugh input; rarely in imaging reports — expect NOT_DOCUMENTED.
- `baseline_assessment.tnm_t` → `Diagnosis.confirmedTStage`: No TNM calculator exists; registry calculatedTStage stays empty.
- `baseline_assessment.child_pugh` → `Diagnosis.calculatedCpScore`, `Diagnosis.calculatedCpGrade`, `ClinicalScore.cpGrade`, `ClinicalScore.cpTotalScore`, `ClinicalSnapshot.cpGrade`, `ClinicalSnapshot.cpTotalScore`: All 5 components required (registry legacy 2-of-5 behaviour is NOT used).
- `baseline_assessment.meld3` → `Diagnosis.calculatedMeld3Score`, `ClinicalScore.meld3Score`, `ClinicalSnapshot.meld3Score`: Requires documented sex; dialysis status must be documented or explicitly NOT_DOCUMENTED.
- `baseline_assessment.bclc_calculated` → `Diagnosis.calculatedBclcStage`, `ClinicalScore.bclcStage`, `ClinicalSnapshot.bclcStage`: Only from clinician-verified inputs. Legacy cascade (stage 0 unreachable) — flagged in ADR-0001.
- `laboratory_episode.afp` → `LabPanel.afpNgMl`: UK labs often report kU/L; registry column is ng/mL. Conversion factor is assay-dependent — never auto-converted.
- `tumour_lesion.target_status` → `Lesion.isTargetLesion`: Target selection is a clinician decision; extraction proposes only.
- `mapping_procedure.dap_gycm2` → `MappingSession.dapGyCm2`: Units vary (Gy.cm2, mGy.m2, uGy.m2); unit captured as documented and never silently converted.
- `procedure_vessel.vessel_name` → `LesionFeeder.vesselName`, `LesionFeeder.feederNumber`: Only TUMOUR_FEEDER vessels linked to a lesion map to LesionFeeder; TARGET/EMBOLISED/MAA_INJECTION roles have no registry home.
- `maa_study.lung_shunt_fraction_percent` → `MaaStudy.lungShuntFraction`: Stored as PERCENT. Registry column is unit-less — push writes percent, matching calculateLungShuntRiskBand.
- `dosimetry_plan.tumour_liver_volume_ratio` → `DosimetryPlan.tumourLiverVolumeRatio`: Definition in registry is UNKNOWN (tumour/whole-liver vs tumour/perfused) — documented value only, never calculated.
- `y90_treatment.delivered_activity_gbq` → `TreatmentSession.administeredActivityGbq`: Never populated from planned/prescribed activity.
- `y90_administration.delivered_activity_gbq` → `LesionDoseInjection.deliveredActivityGbq`: Maps to LesionDoseInjection only when the position is clinician-linked to a lesion (and optionally feeder).
- `post_treatment_dosimetry.delivered_tumour_dose_gy` → `LesionDoseInjection.deliveredDoseGy`: Lesion-level registry column: populated only when the dose is documented for a specific lesion.
- `follow_up_episode.interval_months` → `FollowUp.intervalMonths`: Divisor 30.4375 days/month, documented in formula version (ADR-0001 notes three legacy divisors).
- `lesion_follow_up.response_recist` → `FollowUp.overallResponse`: Only when baseline and follow-up measurements of the same lesion exist; written to a lesion-scoped FollowUp row.
- `lesion_follow_up.response_mrecist` → `FollowUp.overallResponse`: Only with viable-diameter measurements at both timepoints.
- `complication.ctcae_grade` → `ToxicityEvent.ctcaeGrade`: Never inferred from narrative.
